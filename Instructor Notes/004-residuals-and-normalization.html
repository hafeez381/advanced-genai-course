01 · Preserve and refine

Keep the representation. Add an update.

A sublayer can build on what earlier layers already know. The shortcut supplies the existing representation; the learned branch supplies changes.

y = x + F(x)
Direct branchLearned branch
Existing x
Update F(x)
Result y
Move the multiplier to 0: the layer preserves x without learning to reconstruct it. Negative updates can reduce or cancel existing features.
Teaching notes & limits

The addition itself has no learned weights. Parameters inside F are trained jointly with the rest of the model. “Residual” means an update relative to x; there is usually no separate supervised target for that update.

At inference, F still runs. The benefit is information reuse in a model that can be trained effectively, not a shortcut that skips compute. Here x is a three-feature illustrative representation. In attention, the full input is a sequence of such vectors; the residual input and output have matching shapes.

Prompt: what should F learn if the best action is to leave the representation alone? Answer: zero. This exact identity statement applies to an unnormalized sum or a pre/peri block with zero update; post-norm still transforms x.

02 · Learning signal

The derivative of the shortcut is 1—or I.

A copied scalar changes one-for-one with its input. A copied vector changes each coordinate one-for-one, without mixing coordinates.

Scalar

d(x)/dx = 1
dy/dx = 1 + F′(x)

For a tiny change h: [(x + h) − x] / h = h / h = 1.

Two-feature vector

∂x / ∂x = I = [1  0;  0  1]

∂x₁/∂x₁ = 1; ∂x₁/∂x₂ = 0. Each coordinate is copied, so only the diagonal contains ones.

Through F alone: gradient = aⁿ
Through x + F(x): gradient = (1 + a)ⁿ

Exact scalar toy: F(x) = ax at every block; incoming loss gradient = 1. Plot shows gradient magnitude; numbers above retain sign. These are different forward mappings, not an empirical model comparison. There is no LayerNorm in this toy.

∂L/∂x = g + F′(x)g
Vector form: ∇ₓL = g + JFTg
Derivation & the important caveat

L is the final scalar training loss. x enters this block; y leaves it. g = ∂L/∂y arrives from later layers. By the chain rule, ∂L/∂x = (∂L/∂y)(dy/dx) = g(1 + F′(x)). Distribute the multiplication to get the two contributions.

For vectors, define (JF)ij = ∂Fᵢ/∂xⱼ. The gradient uses its transpose because ∂L/∂xⱼ = Σᵢ (∂L/∂yᵢ)(∂yᵢ/∂xⱼ). All model weights are held fixed in this derivative.

The direct contribution is preserved, but the total gradient can still vanish (a = −1 cancels it exactly) or grow. A residual connection does not guarantee stable gradients.

03 · Normalize one token

Subtract the mean. Divide by the spread.

LayerNorm operates across the features of one token. It then applies learned feature-wise scales and offsets.

x = c × [1, 2, 3, 4] + b. ε = 0.00001 throughout these normalization demonstrations.

Change the common offset, then compare steps 1 and 3. The raw values move; the standardized pattern stays the same.
Parameters, statistics & information

μ = (1/d)Σᵢxᵢ; σ² = (1/d)Σᵢ(xᵢ − μ)². LN(x)ᵢ = γᵢ(xᵢ − μ)/√(σ² + ε) + βᵢ. Here d = 4. The last step uses γ = [1, 0.5, 1.5, 1] and β = [0, 0.5, −0.5, 0] to show that the final output need not have mean zero or variance one.

μ and σ² are recomputed per token. Each normalization module learns its own γ and β, shared across all tokens using that module. The learned affine transform does not recover the particular mean and scale discarded for each input.

For a tensor [batch, sequence, d_model], normalize across d_model. This does not mix examples or tokens, does not make the distribution Gaussian, and does not impose a fixed bound when learned scales change.

Source: Ba, Kiros & Hinton, Layer Normalization (2016).

04 · Which values belong together?

LayerNorm groups rows. BatchNorm groups columns.

Each row below is one example with three features. Matching colors mark the values used together for normalization.

Input matrix

Normalized matrix

Why Transformers usually use per-token normalization

In this simplified [examples, features] matrix, BatchNorm estimates each feature's mean and variance across examples. LayerNorm estimates each example's statistics across its features. Learned γ = 1 and β = 0 are used here.

Training BatchNorm normally uses current batch statistics and tracks running estimates for inference. LayerNorm recalculates statistics from each token at both training and inference. BatchNorm depends on batch composition; small effective batches can yield noisy statistics. In images or sequence implementations, BatchNorm may also pool spatial or temporal positions—the exact axes must be specified.

Prompt: if example B changes, should example A's LayerNorm output change? No. Can A's training-time BatchNorm output change? Yes.

Source: Ioffe & Szegedy, Batch Normalization (2015).

05 · The central comparison

Post → output → pre → peri

Follow the shortcut. Then ask whether the input to F, its update, or the combined sum is normalized.

Animation shows routes; dot size does not encode gradient magnitude.

What remains unresolved?

Progression, derivatives & naming

This is a teaching order, not a historical timeline or a ranking. Original post-norm is N(x + F(x)). Swin V2's “residual-post-norm” and OLMo 2's “reordered norm” refer to output normalization, x + N(F(x)); the formulas disambiguate similar names.

For post-norm, define q = JNTg, with JN evaluated at x + F(x). Then ∇ₓL = q + JFTq: even the shortcut receives a gradient already transformed by N. For output, pre, and peri, write the whole branch as H; ∇ₓL = g + JHTg. This preserves one direct contribution, not the magnitude of the total gradient.

Pre-norm does not dominate output norm: one controls F's input, the other its update. Peri combines them at extra cost. The Peri-LN paper found output-only divergence in one ablation; this is not a universal impossibility result. OLMo 2 uses output normalization successfully with QK-norm and its broader training recipe.

A final normalization commonly follows a pre/peri stack. A norm at that final boundary does not remove the identity routes inside the stack. Each sublayer uses separate normalization parameters. Dropout is omitted from this diagram for clarity.

Sources: Xiong et al. (2020); Swin V2; OLMo 2; Peri-LN.

06 · What can output normalization miss?

Scale can change the attention decision.

With fixed bias-free projections, scaling every input by s scales both queries and keys by s. Their dot products scale by s².

q = s[1, 0]   k₁ = s[0.8, 0.6]   k₂ = s[2, 0]

Ordinary dot-product attention

Scores = q·kᵢ / √2

QK-normalized attention

Scores = 2 × (q/‖q‖)·(kᵢ/‖kᵢ‖)

Unit-length Q/K; fixed demonstration gain = 2. Their directions remain unchanged as s changes.

If attention already selected almost only value 2, normalizing its output afterward does not rerun softmax or restore the original mixture.
Exact setup, values & implementation choices

The two keys correspond to value vectors v₁ = [1, 0] and v₂ = [0, 1]. Thus the attention output before output projection is exactly [p₁, p₂], the two displayed attention weights. The result follows directly from p₁v₁ + p₂v₂.

This is an L2-normalized QK illustration, inspired by Henry et al. (2020). Other implementations use RMSNorm, normalize per head or across projected dimensions, and choose different score scaling. Do not assume all QK-norm variants are numerically identical.

QK-norm changes which aspects of q and k affect their score; it is not algebraically equivalent to ordinary attention. It limits sensitivity to their magnitudes but does not guarantee high attention entropy under every learned gain or representation. Pre-norm also controls global input scale, but learned projection weights can still amplify q and k.

Sources: Query-Key Normalization for Transformers; OLMo 2, §3.3.2.

07 · How to normalize

Center and rescale—or just rescale?

Normalization placement and normalization formula are separate choices. RMSNorm retains scale control while dropping mean subtraction.

LayerNorm

(xᵢ − μ) / √(σ² + ε)

RMSNorm

xᵢ / √(mean(x²) + ε)
Shift all features together: LayerNorm removes that offset; RMSNorm responds to it. Both are approximately invariant to positive rescaling when ε is negligible.
What is removed, what is learned & what it costs

Demonstration settings: γᵢ = 1, LayerNorm βᵢ = 0. Standard RMSNorm uses a learned scale vector and usually no additive bias. Actual normalized outputs need not keep RMS or variance equal to one after learned scaling.

RMS² = variance + mean². Thus RMSNorm changes the denominator as well as removing centering from the numerator. It preserves each input vector's direction before feature-wise γ; LayerNorm first removes its component along the all-ones direction.

Both take O(d) work per token. RMSNorm uses fewer operations; end-to-end speedup depends on hardware, fusion, and the share of runtime spent on normalization. It does not by itself fix placement-related gradient or residual accumulation problems.

Source: Zhang & Sennrich, Root Mean Square Layer Normalization (2019).

08 · How large should an update be?

Normalized updates can still accumulate.

Every update in this toy has RMS exactly 1 before scaling. Alignment determines how their sum grows.

x₀ = 0    xℓ+1 = xℓ + αuℓ,   RMS(uℓ) = 1

Exact 2D construction, not measured Transformer activations. uℓ = √2[cos(θℓ + π/4), sin(θℓ + π/4)]. Learned normalization gains can also change real update scales.

DeepNorm: a different, coordinated recipe
y = LayerNorm(αx + F(x))

DeepNorm scales the shortcut before post-norm and adjusts the initial scale of selected branch weights. These two choices are coordinated with model depth. The α in this equation scales x; the slider above scales updates in a generic toy. They are not the same recipe.

For an N-block encoder-only or decoder-only model in the paper's setting: α = (2N)1/4, and initialization gain β = (8N)−1/4 for FFN weights and attention value/output projections. Query/key projection initialization is not scaled by β. Encoder–decoder constants differ. This β is not LayerNorm's learned offset.

The paper demonstrated training at up to 1,000 layers. LayerNorm remains on the shortcut route, so its rationale is controlled model updates with depth-aware initialization, not restoring an untouched identity route. Wang et al., DeepNet (2022).

09 · Supporting training concept

Learn to work with missing activations.

Dropout randomly removes some activations during training. Surviving values are scaled so each value's expected contribution stays the same.

Original branch output

After training-time dropout

Original Transformer: y = LN(x + Dropout(F(x)))
The mask changes; weights are not deleted. During ordinary inference, dropout is off and all activations are used.
Expectation, gradients & limitations

Inverted dropout uses D(aᵢ) = mᵢaᵢ/(1 − p), where mᵢ is 1 with probability 1 − p, otherwise 0. E[D(aᵢ)] = (1 − p)aᵢ/(1 − p) = aᵢ. This preserves the expected activation, not the output of every downstream nonlinear operation.

The displayed random mask may drop more or fewer than p times the number of coordinates. A dropped coordinate has zero gradient through this particular dropout branch on this pass; the residual route still exists. In original post-norm it then crosses LayerNorm.

Dropout aims to reduce overfitting, not to normalize activations or guarantee training stability. Too much can hinder fitting. The original Transformer base model used p = 0.1 on sublayer outputs and embedding/position sums. Vaswani et al. (2017); Srivastava et al. (2014).

10 · Supporting training concept

Make the first weight updates small.

A large early gradient need not cause a large step if the learning rate is small. Warm-up gradually increases the learning rate while training is already happening.

Illustrative schedule: linear rise to peak 0.001, then inverse-square-root decay. Peak is held fixed when T changes. The SGD calculation is illustrative; the original Transformer used Adam.

ηₜ = ηpeak min(t/T, √(T/t))
wnew = w − ηₜ ∂L/∂w
Connect warm-up to post-norm

Initialization means the starting weights before learning. Large expected parameter gradients near the output were identified for original post-norm under the assumptions of Xiong et al. (2020). A small initial learning rate limits the resulting early updates. It does not directly clip or normalize those gradients.

Pre-norm improves gradient behavior in that analysis, but does not imply all modern models should omit warm-up. The original Transformer used 4,000 warm-up steps with ηₜ = d_model−1/2 min(t−1/2, tT−3/2); unlike this plot's fixed-peak illustration, its peak depends on both d_model and T.

Sources: Attention Is All You Need; On Layer Normalization in the Transformer Architecture.

11 · Bring the choices together

Three separate design decisions.

What travels onward?

Residuals carry the current representation and add an update.

Where is scale controlled?

At F's input, its output, or after residual addition.

How is it controlled?

LayerNorm, RMSNorm, QK-norm, scaling, and initialization play distinct roles.

Questions to ask the class
  1. Which three placements preserve an identity route? Output, pre, peri.
  2. Can an output norm undo an already peaked softmax? No: it does not recompute attention weights.
  3. Does γ, β guarantee zero mean and unit variance? No: those properties refer to the standardization step, approximately with ε.
  4. Is RMSNorm the successor to peri-norm? These are separate axes: RMSNorm can be used inside peri-norm.
  5. Does the shortcut reduce inference compute? No: F is still evaluated.
